# Tutoring AI Platform

AI-powered course registration platform using:

- Java Spring Boot Microservices
- AWS Bedrock RAG
- OpenSearch
- React
- AWS ECS

## Services

- gateway-service
- auth-service
- student-service
- course-service
- enrollment-service
- notification-service
- rag-orchestrator-service

## Architecture

Microservices + Event Driven + AI RAG
